# Software Modelling Labs

## Lab 1
Introductory Java exercises: variables, ArrayList, loops, debugging,
conditionals, Student objects, and an extension Dog class.

## Lab 2 - sd3zoo
Zoo modelling project using packages, private properties, constructors,
getters/setters, interfaces and polymorphism.

Open `Lab1` or `sd3zoo` as a project in IntelliJ IDEA and configure a Java JDK.
